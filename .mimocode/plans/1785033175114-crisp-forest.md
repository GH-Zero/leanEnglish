# 英语学习小程序完善计划

## 问题诊断总览

对照流程图，发现以下核心问题：

---

## 一、关键 Bug 修复

### 1. phonetic/index.vue — masteredCount 永远为 0
- `masteredCount` 在 data 中初始化为 0，但整个 script 中从未更新它
- 需要从 storage/phoneticProgress 中加载已掌握的音标数量
- **修复**：在 `onLoad` 中调用 `getPhoneticProgress()` 计算已掌握数量

### 2. phonetic/index.vue — 录音结束回调逻辑错误
- `recordManager.onStop` 中先设 `isRecording = false`，然后调用 `evaluateRecording`，但 `evaluateRecording` 内部又调用 `callEvaluateAPI` 显示 loading
- `isRecording` 被重复设置，流程没问题但需要确保 `masteredCount` 在评分后更新
- **修复**：评分成功后更新 masteredCount 并保存进度

### 3. word/index.vue — playWord 使用过时 API
- `uni.playVoice` 在新版 UniApp 中已废弃，应使用 `uni.createInnerAudioContext()`
- **修复**：替换为 `InnerAudioContext` 播放

### 4. dialogue/index.vue — 录音回调中 isRecording 双重设置
- `onStop` 回调里已经设 `isRecording = false`，但 `toggleRecording` 里 stop 后又立即设 `false`
- 不是严重 bug，但逻辑混乱
- **修复**：统一在 `onStop` 回调中管理状态

### 5. dialogue/index.vue — AI 回复无上下文
- 每次 AI 回复都是随机选择，不基于用户说了什么
- **修复**：至少根据场景关键词匹配，给出更相关的回复

### 6. statistics.vue — weekData 使用模拟随机数
- `storage.js:516` 的 `calculateWeekData()` 中使用 `Math.random()` 生成模拟数据
- **修复**：使用 daily_record 中的真实数据

---

## 二、功能完善

### 7. learn/index.vue — 学习进度为硬编码 0%
- 进度条全部写死为 `style="width: 0%"`，从未加载真实数据
- **修复**：从 storage 加载 phonetic/word/grammar 进度，动态绑定到进度条

### 8. speak/index.vue — 缺少影子跟读入口
- 流程图要求有"播放句子 → 录音跟读 → 发音评分与建议"
- 当前只是静态列表，跳转到 phonetic/word 页面
- **修复**：添加句子跟读功能入口，使用跟读素材表

### 9. challenge/index.vue — 闯关结果不记录
- 流程图要求"完成每日练习 → 记录学习成果 → 学习数据中心"
- 当前闯关完成后不更新任何统计数据
- **修复**：闯关完成后调用 `updateWordStats`/`updateGrammarStats`/`updateSpeakStats` 更新统计

### 10. 音标/单词/语法模块缺少"更新 SRS 复习计划"闭环
- 流程图要求每次练习后"更新 SRS 复习计划与单词状态"
- 单词模块的 SRS 在后端已实现（word.js），但前端 `markKnown`/`markUnknown` 调用后没有同步更新本地状态
- **修复**：确保每次标记后同步更新 storage 中的 word_status

### 11. 数据中心闭环缺失
- 流程图要求所有模块的学习成果汇聚到"学习数据中心"，再反馈到首页
- 当前首页的统计数据从 API 获取，但很多模块（phonetic、grammar）只更新本地统计
- **修复**：确保所有模块在完成学习后都调用 `updateXxxStats()` 更新统一统计
