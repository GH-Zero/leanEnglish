# 单词词库后端动态管理方案

## 目标
将单词数据从前端静态写死改为后端数据库存储 + 前端按需拉取 + 本地缓存。

## 一、后端改动

### 1. 新增 words 字典表
文件：`server/database-sqlite.js`

```sql
CREATE TABLE IF NOT EXISTS words (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    word TEXT UNIQUE NOT NULL,
    phonetic_us TEXT,
    phonetic_uk TEXT,
    chinese TEXT,
    example TEXT,
    level INTEGER DEFAULT 0,        -- 0零基础/1初级/2中级
    tag TEXT DEFAULT '通用',
    sort_order INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2. 新增单词导入脚本
文件：`server/import-words.js`

从内置JSON数据批量导入单词到数据库，支持重复运行（UPSERT）。

### 3. 新增单词API路由
文件：`server/routes/words-dict.js`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/words/list` | 获取单词列表（支持 level、page、pageSize 参数） |
| GET | `/api/words/detail/:id` | 获取单词详情 |
| GET | `/api/words/random` | 随机获取指定数量的单词 |
| GET | `/api/words/count` | 获取各等级单词数量统计 |

### 4. 注册路由
文件：`server/index.js` — 注册新路由

## 二、前端改动

### 1. 新增单词API函数
文件：`src/utils/api.js`

```js
export function getWordList(params)    // params: { level, page, pageSize }
export function getWordRandom(params)  // params: { level, count }
export function getWordCount()
```

### 2. 重写单词页面
文件：`src/pages/word/index.vue`

- 选择词库时调用 `getWordRandom({ level, count: 20 })` 从后端获取
- 每次学习20个新词，复习词从本地缓存获取
- 后端返回的数据直接使用，不再调用外部API获取音标释义
- 本地缓存学习进度到 Storage

### 3. 删除外部API依赖
- 删除 `src/utils/wordApi.js`（不再用 Free Dictionary API）
- 删除 `src/data/words.js`（不再有本地单词列表）

## 三、单词数据

使用内置数据（180个单词），分为3个等级：
- level 0：基础词汇（60个）
- level 1：日常交流（60个）
- level 2：进阶词汇（60个）

数据以JSON格式嵌入 `import-words.js`，运行导入脚本写入数据库。

## 五、验证步骤

1. 启动后端：`cd server && node index.js`
2. 导入单词：`node import-words.js`
3. 测试API：`curl http://localhost:3000/api/words/list?level=0&page=1&pageSize=10`
4. 启动前端：微信开发者工具刷新
5. 验证：选择词库 → 从后端加载单词 → 显示音标、释义、例句
