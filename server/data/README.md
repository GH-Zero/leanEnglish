# 36,000-word data package

`words-36000.json.gz` contains 36,000 English learning entries generated from the project's existing words and the ECDICT English-Chinese dictionary.

- Source: https://github.com/skywind3000/ECDICT
- License: MIT (see `ECDICT-LICENSE.txt`)
- Categories: 名词、动词、形容词、副词、功能词、其他
- Import: `npm run import-words-36000`
